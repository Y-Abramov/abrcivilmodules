# AbrCivilModules - Библиотека модулей

Первый модуль линейки **ABR | CIVIL** для Autodesk Civil 3D 2024/2026: каталог модулей,
установка, обновление и удаление `.bundle` без прав администратора.

Файлы кладутся в профиль пользователя (`%AppData%\Autodesk\ApplicationPlugins`), поэтому
установка не требует UAC. Изменения вступают в силу после перезапуска Civil 3D.

## Установка

Распаковать `.bundle` из релиза в `%AppData%\Autodesk\ApplicationPlugins\` и перезапустить
Civil 3D. Дальнейшие модули линейки можно ставить и обновлять из окна «Библиотека модулей».

## Установка одним файлом

`AbrCivilSetup.exe` из релиза ставит линейку без ручной распаковки:

1. Закрыть Civil 3D.
2. Запустить `AbrCivilSetup.exe`. Windows может показать «Неизвестный издатель» -
   «Подробнее» - «Выполнить в любом случае» (файл не подписан цифровой подписью).
3. Отметить нужные модули. «Библиотека модулей» ставится всегда.
4. Запустить Civil 3D - модули появятся на вкладке ленты «Модули».

Снятая галка при установке означает «не трогать». Чтобы удалить модули, на первом шаге
нажмите «Удалить модули», отметьте ненужные и нажмите «Удалить» (Civil 3D должен быть закрыт).
Настройки и пресеты сохраняются; по галке очищается кэш загрузок (карты, рельеф).
Удаление и отключение также доступны в окне «Библиотека модулей» (команда `ABRSTORE`) внутри Civil 3D.

Кнопка «Требования» на первом шаге показывает технические требования: Windows 10/11 x64,
Civil 3D 2015-2026, .NET Framework 4.8, доступ к GitHub или зеркалу.

## Команды

| Команда | Действие |
|---------|----------|
| `ABRSTORE` | открывает окно «Библиотека модулей» |
| `ABRABOUT` | диалог «О модуле» |
| `ABRSITE` | сайт разработчика |
